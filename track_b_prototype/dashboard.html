Gaps and inconsistencies in the input data. Resolve these before trusting any single number.

  • Defect mismatch: lines total 137, machines total 84.
  • Batch B004 (output 820) matches no production line. Its line of origin is unknown.
  • Line data covers one day, but the brief's evaluation period is 30 days. No monthly figure can be computed from this data.

How it works

Rules and KPIs flag lines, machines and batches that need a look.

Explain

Every number shows its inputs and formula, so it can be challenged.

A person reviews each item and decides what to do. Nothing is automatic.
